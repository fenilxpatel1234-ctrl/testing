## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `API_KEY` in [.env.local](.env.local) to your API key
4. `Most preferred api is gemini api key`
5. Run the app:
   `npm run dev`
